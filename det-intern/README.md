# Frontend Redesign – Excellence International School

## Project Overview

This project is a modern UI/UX redesign of the official Excellence International School website using React and Tailwind CSS. The primary goal of this project is to preserve the school's core content while significantly improving the overall user experience, visual aesthetics, and accessibility.

## Installation

To run this project locally, execute the following commands:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```

## Features

- **Dynamic Navigation:** Glassmorphic sticky header that transitions on scroll.
- **Hero Section:** Infinite scrolling background slider with premium typography.
- **Scroll Animations:** Smooth entry animations for all major sections using Framer Motion.
- **Responsive Design:** Fluidly adapts from 320px mobile screens up to 1920px ultra-wide monitors.
- **Routing:** Client-side routing with React Router, including a custom 404 page.

---

## Responsive Support

The website is fully optimized for:
- Mobile Devices (320px - 425px)
- Tablets (768px - 1024px)
- Desktops & Ultra-wide (1280px - 1920px+)
